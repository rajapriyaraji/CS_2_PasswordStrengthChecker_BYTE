# Password Strength Checker

This project was developed as part of the AVIP 2026 CyberSecurity Internship.

## About the Project

The Password Strength Checker is a Python program that evaluates the strength of a password based on different security rules.

The program classifies passwords as:

- Weak
- Moderate
- Strong

## Password Rules

A secure password should contain:

- At least 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character

## Technologies Used

- Python
- Regular Expressions
